Acronyms for the SY0-801 exam

AESAdvanced Encryption StandardThe current standard symmetric block cipher, with 128, 192 or 256-bit keys.1.3
AI *Artificial IntelligenceSystems that learn from data to predict, classify or generate; both a tool and a target.2.6
ALE *Annualized Loss ExpectancyExpected loss from a risk in one year: SLE x ARO.5.2
AML/CTF *Anti-money Laundering/Counter-terrorism Financing (counter-terrorist financing)Rules and training that stop an organization being used to move criminal or terrorist money.5.4

APT *Advanced Persistent ThreatA skilled, well-funded attacker who stays hidden in a network for a long time.2.3
ARO *Annualized Rate of OccurrenceHow many times a year a loss event is expected to happen.5.2

CAPTCHA *Completely Automated Public Turing test to tell Computers and Humans ApartA challenge meant to stop bots; fake CAPTCHAs are now used to trick users.2.3
CCTVClosed-Circuit TelevisionVideo cameras that record to a private system; a detective and deterring physical control.1.1
CEOChief Executive OfficerThe head of an organization; a favorite target of impersonation and whaling.2.5

CI/CD *Continuous Integration and Continuous Deployment (or Delivery)Automated building, testing and release of code; security checks run in the pipeline.4.6

CISOChief Information Security OfficerThe senior leader responsible for the security program.5.1

CSPM *Cloud Security Posture ManagementTools that scan cloud settings for misconfigurations and compliance gaps.4.3

DNS *Domain Name SystemTurns names into IP addresses; a target for poisoning and a source of attack clues.2.5
DoS *Denial of ServiceAn attack that makes a service unavailable, from one source.2.5
DRDisaster RecoveryRestoring IT systems and data after a major disruption.3.4
DRPDisaster Recovery PlanThe written plan for restoring IT systems after a disaster.5.1
DSADigital Signature AlgorithmAn older signature algorithm, no longer approved for new signatures.1.3
